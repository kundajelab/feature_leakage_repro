# Data

Every input is resolved through `common/config.py`, which checks, in order, a
`FEATLEAK_<KEY>` environment variable, `common/paths.yaml`, and the default locations
(including the files in this folder). Run `python -m common.config` to see what resolves.

`data_availability.xlsx` lists every public dataset and model used, with accession
numbers and download links, and which resources are generated by the code.

## Public data and generated inputs

| config key | content | source |
|------------|---------|--------|
| `hg38_fasta` | GRCh38 reference genome | UCSC `hg38.fa.gz` |
| `peaks_dermis` | DNase-seq peaks, fibroblast of dermis | ENCODE ENCFF184KAM (ENCSR000EPO) |
| `bigwig_dermis` | DNase-seq signal, fibroblast of dermis | ENCODE ENCFF302JEV (ENCSR000EPO) |
| `peaks_fibroblast` | DNase-seq peaks, cardiac fibroblast | ENCODE ENCFF942AKV (ENCSR000ENH) |
| `fimo_octsox` | genome-wide FIMO matches of the Vierstra v2.0beta archetype AC0636 (OCT–SOX) | generated with FIMO |
| `assoc_octsox`, `assoc_ap1`, `assoc_hnf4`, `assoc_ctcf` | genome-wide FIMO matches of JASPAR MA0142.1, MA0476.1, MA0114.4, MA0139.1 | generated with FIMO |
| `jaspar_meme` | JASPAR 2022 CORE vertebrates (non-redundant), MEME format | JASPAR |

ENCODE files can be downloaded from https://www.encodeproject.org. The FIMO match files are
generated with default parameters (P < 1e-4), for example:

```bash
fimo --text --thresh 1e-4 MA0142.1.meme hg38.fa > oct-sox.txt
```

Consensus sequences used for insertions are in `common/motifs.py`: AP-1 `ATGAGTCAC`,
OCT–SOX `ATTGTTATGCAAAT`, CTCF `GCCGCCAGGGGGCGCCG`, HNF4 `CAAAGTCCA`.
