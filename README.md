# Feature Leakage — Figure Reproduction

Code, environments and source notebooks for the figures of
*"Multi-task sequence-to-omics models learn spurious off-target predictive motif
associations across cell contexts"* (Obbad, Nair, Min, Noble, Schreiber, Kundaje; 2026).

The paper shows that multi-task sequence models (DeepSEA/Beluga, Enformer, Borzoi,
AlphaGenome) assign biologically implausible effects to well-understood motifs in
off-target cell contexts (e.g. predicting that OCT–SOX insertion lowers fibroblast
accessibility), that biased training-locus selection and multi-task objectives produce
these associations, that model-guided design exploits them, and that a matched
single-task model (ChromBPNet) can guide fine-tuning to attenuate one of them.

Please reach out with questions.

## Layout

```
feature_leakage_repro/
  common/              shared, framework-agnostic code
    config.py            central path registry (edit here to re-home data)
    paths.yaml           optional per-machine path overrides
    beluga_model.py      vendored PyTorch Beluga/DeepSEA + datasets/probe
    models.py            model loaders (Beluga, ChromBPNet, AlphaGenome, gReLU, SEI)
    motifs.py            Vierstra motif tables + canonical consensus strings
    motif_controls.py    shuffled-motif controls
  env/                 conda environment specs + setup_envs.sh
  data/README.md       data provenance + ENCODE accessions
  models/README.md     how to download each model weight (git-ignored dir)
  figures/figureN/     Figures 1–6: scripts, README, notebooks/ (source notebooks), outputs/
  experiments/
    ag_deleak_finetune/  Figure 7 (ChromBPNet-gated fine-tuning of AlphaGenome)
    tf_chip_leakage/     Supplementary Fig 2e–g (REST ChIP-seq, AlphaGenome vs BPNet)
  alphagenome_finetune/  JAX AlphaGenome helpers (alphagenome-ft) used by older runs
  tools/               render_with_svg.py, pdf_to_png.py
  Makefile             convenience targets
```

Scripts write their outputs to `figures/figureN/outputs/` or `experiments/<name>/outputs/`
(git-ignored; regenerated by the scripts).

**Source notebooks.** Figures 3, 4, 5 and 6 (and the AlphaGenome column of Supp Fig 1a)
were produced in the original analysis notebooks, which are included verbatim under each
figure's `notebooks/` folder with their saved outputs. Their numbers are the published
ones. The `run_*.py` scripts in the same folders reimplement those analyses with the same
helper code; several steps draw unseeded random sequences, so script reruns reproduce the
published results qualitatively but not to the digit.

## Environments

| env | stack | used by |
|-----|-------|---------|
| `featleak-dl` | PyTorch 2.7 (cu118), tangermeme 0.5, bpnet-lite, gReLU, modiscolite | most panels: Beluga, ChromBPNet, Borzoi/Enformer, Figs 3–6 |
| `featleak-agtorch` | PyTorch 2.5 + [`alphagenome-pytorch`](https://github.com/rastogiruchir/alphagenome-pytorch) (all-folds v1 weights) | full-length (524,288 bp) AlphaGenome: Figs 1a, 1c, 2b, 7 |
| `featleak-alphagenome` | JAX, local AlphaGenome v1 | JAX AlphaGenome runs (Supp Fig 2b, REST panels) |
| `alphagenome-ft` | JAX + [`alphagenome-ft`](https://genomicsxai.github.io/) | older JAX fine-tuning runs (`alphagenome_finetune/`) |
| `featleak-tf` | TensorFlow/Keras 2.15, tf-modisco | Fig 4b TF-MoDISco notebook |

```bash
bash env/setup_envs.sh              # clone from the working lab envs (fast, exact)
bash env/setup_envs.sh --from-yml   # or solve from the environment.yml files (portable)
```

GPUs: pass `CUDA_VISIBLE_DEVICES=<id>`. Full-length AlphaGenome runs need
`PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True` on a 46 GB GPU. Paths in
`common/config.py` assume the Kundaje-lab layout under `/oak/stanford/groups/akundaje`
and `/users/kobbad/feat_leakage`; override via env vars / `common/paths.yaml` elsewhere.
Check that all data resolves with `python -m common.config`.

## Model weights

Download into `models/`; `common/config.py` looks there first. Details in
[`models/README.md`](models/README.md).

| model | where to get it | put in |
|-------|-----------------|--------|
| **Beluga / DeepSEA** (~570 MB) | Kipoi [`DeepSEA/beluga`](http://kipoi.org/models/DeepSEA/beluga/) | `models/deepsea.beluga.pth` |
| **ChromBPNet** (~25 MB each) | ENCODE4 ChromBPNet models — Hugging Face [`kundajelab`](https://huggingface.co/kundajelab) or Synapse [`syn59449898`](https://www.synapse.org/Synapse:syn59449898/files/); bias-corrected (`wo_bias`) `.h5`, fold 0 | `models/chrombpnet/<ENCSR>_chrombpnet_wo_bias.h5` |
| **BPNet (REST ChIP-seq)** | ENCODE BPNet models for ENCSR137ZMQ, ENCSR054JMQ, ENCSR000BMW, ENCSR000ATM (5 folds) | see `experiments/tf_chip_leakage/` |
| **Borzoi / Enformer** | auto-downloaded by [gReLU](https://github.com/Genentech/gReLU) | (cached by gReLU) |
| **AlphaGenome v1** (~730 MB) | access-restricted (Google DeepMind) | `models/alphagenome-v1/` |
| **AlphaGenome PyTorch weights** | [`gtca/alphagenome_pytorch`](https://huggingface.co/gtca/alphagenome_pytorch) `model_all_folds.safetensors` | `models/alphagenome-pytorch/` |

**ENCSR000EPO** (fibroblast of dermis): AlphaGenome track CL:0002551, Enformer/Borzoi task
ENCFF302JEV, ChromBPNet trained on ENCSR000EPO, enhancers from its peaks (ENCFF184KAM).
